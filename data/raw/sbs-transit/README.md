# SBS Transit Published LRT Travel Times

`lrt_travel_times.csv` is a manual transcription of the adjacent station timings shown in
SBS Transit's travel-time image charts:

- `SELRT.jpg`: Sengkang East Loop
- `SWLRT.jpg`: Sengkang West Loop
- `PELRT.jpg`: Punggol East Loop
- `PWLRT.jpg`: Punggol West Loop

Source page: https://www.sbstransit.com.sg/travel-time

Transcribed 2026-07-07. These rows are used only for the SBS-operated Sengkang and Punggol
LRT loops. Bukit Panjang LRT is not operated by SBS Transit and continues to use the
SimplyGo-derived fallback.
